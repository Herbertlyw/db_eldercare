# 界面图片素材

生活照和社区场景由内置 imagegen 生成，人物均为虚构，不对应真实身份或真实服务记录。图片随项目本地提供，不依赖外部图片网站。登录页使用蓝色社区建筑插画，品牌标志为两栋相邻住宅的 SVG 图形。

老人照片采用日常手机随手拍的构图，人物、衣服、环境和光线各有区别。`demo-people.json` 按编号和姓名固定关联照片，列表、档案详情和家属页面共用同一对应关系。36 张独立照片覆盖 24 位基础种子人物及 12 位邻里示例人物，不重复使用人像。未匹配的档案和图片加载失败的档案显示姓名首字；工作账号使用角色文字标识。

“社区陪伴”包含散步、聊天、包饺子和使用手机四张生活照片，正常每 5.5 秒切换，通过照片下方的小圆点选择图片，旁边的小按钮控制暂停和播放，控件不覆盖照片。鼠标悬停、键盘焦点在卡片内、页面隐藏或卡片移出视野时暂停；系统设置“减少动态效果”时默认关闭自动播放。图片加载失败时保留当前照片，并跳过失败项。
