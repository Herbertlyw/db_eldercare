## 需要明确区分的项目规则

复评采用最新已生效评估，当前复评暂停旧计划，后续服务按最新评估制定计划。跨社区迁移前处理未完成订单并解绑设备，设备继续由原社区管理。通知按本社区责任分发，跨社区查询授权与通知接收范围分开。这三项是项目对关联流程的处理方案，任务书没有逐条规定这种实现方式。

招聘培训、投诉办理、比例抽查、整改复核、公示、机构考核及辖区统计属于任务书业务范围。培训及整改分数、响应秒数、工时比例、虚构围栏和补贴金额属于演示配置。系统支持本地演示，不表示真实医疗、支付、短信或硬件接入。

本机运行与数据库验证环境为 macOS arm64、Java 17、原生 MySQL 8.4.11。Windows 脚本提供初始化及启动方式，实机结果尚未具备。备份恢复演练验证受控数据集，不等同于长期自动灾备或已经达成 RPO/RTO。
