# 数据字典与关系模式

本文件根据实际运行数据库的 information_schema 生成。PK 表示主键，FK 表示外键。所有基础表至少有 20 条虚构测试记录；有限角色与状态使用枚举字段，不建立需要凑数的小型字典表。

## 社区 community

关系模式：community(id [PK], name, district, area_code)。

| 字段 | 粗略类型 | 实际类型 | 允许空值 | 默认值 | 含义与约束 |
| --- | --- | --- | --- | --- | --- |
| id | 数字型 | bigint | NO | NULL | 内部唯一编号；主键、自增；auto_increment |
| name | 字符型 | varchar(80) | NO | NULL | 业务对象名称 |
| district | 字符型 | varchar(80) | NO | NULL | 所属演示区县 |
| area_code | 字符型 | varchar(30) | NO | NULL | 社区服务范围编码；唯一索引 |

| 字段 | 粗略类型 | 实际类型 | 允许空值 | 默认值 | 含义与约束 |
