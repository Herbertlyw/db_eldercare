# 数据字典与关系模式

本文件列出 47 张基础表的关系模式和字段，与 database/01_schema.sql 及 evidence/schema-columns.tsv 中的结构对应。PK 表示主键，FK 表示外键。所有基础表至少有 20 条虚构测试记录；有限角色与状态使用枚举字段，不建立需要凑数的小型字典表。

## 社区 community

关系模式：community(id [PK], name, district, area_code, street_name, center_x, center_y, radius_m, fence_m)。

| 字段 | 粗略类型 | 实际类型 | 允许空值 | 默认值 | 含义与约束 |
| --- | --- | --- | --- | --- | --- |
| id | 数字型 | bigint | NO | NULL | 内部唯一编号；主键、自增；auto_increment |
| name | 字符型 | varchar(80) | NO | NULL | 业务对象名称 |
| district | 字符型 | varchar(80) | NO | NULL | 所属演示区县 |
| area_code | 字符型 | varchar(30) | NO | NULL | 社区服务范围编码；唯一索引 |
| street_name | 字符型 | varchar(80) | NO | 演示街道 | 所属街道名称 |
| center_x | 数字型 | decimal(12,3) | NO | 0.000 | 虚构平面坐标中心横坐标，米 |
| center_y | 数字型 | decimal(12,3) | NO | 0.000 | 虚构平面坐标中心纵坐标，米 |
| radius_m | 数字型 | int | NO | 5000 | 社区服务范围半径，必须为正数 |
| fence_m | 数字型 | int | NO | 200 | 签到签退允许距离，必须为正数 |
