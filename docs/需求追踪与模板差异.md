# 课程要求与实现对照

本表依据任务书、教师讲解、小组和个人报告模板及评分标准。任务书给出业务和数据库最低要求，报告模板规定具体提交结构；项目的技术选型和演示参数在需求分析中单独说明。

| 依据与要求 | 实现或材料位置 | 验证方式 |
| --- | --- | --- |
| 任务书五条业务线及五类使用人员 | 七个 application/service 业务服务；六种系统角色 | 功能验收清单中的操作与测试对应 |
| 模板的用例、鲁棒分析、数据项与非功能分析 | 需求与整体设计思路.md；diagrams/A 至 E 的 usecase、robustness 图 | 报告第二章与模型、字段对应 |
| 全局与局部 E-R 或 UML 类图 | diagrams/global-uml.svg 及局部 UML | 以 01_schema.sql 的主外键为准 |
| 逻辑模式及第三范式分析 | 逻辑设计与范式分析.md、数据字典与关系模式.md | 候选键、函数依赖及历史快照说明 |
| 物理字段、约束和索引 | database/01_schema.sql | 空库导入与真实 MySQL 测试 |
| 每表不少于 20 条测试数据 | infrastructure/bootstrap/Seed.java；evidence/row-counts.json | everyTableHasTwentyRows；47 张基础表 |
| 任务书至少 5 条连接不少于 3 个关系的查询 | database/04_queries.sql 中 A1、B1、B3、C1、D1 等 | 查询源 SQL 与执行计划 |
| 小组模板每业务 3 个查询、每个两种实现 | database/queries.json、04_queries.sql；共 15 组 30 条 | evidence/query-comparison.json 逐行等价 |
| 每业务至少 3 个实用视图 | database/03_views.sql，15 个业务视图 | fifteenViewsExecute；授权查询入口 |
| 任务书每业务过程或触发器，模板每业务各有过程和触发器 | database/02_routines.sql；共 10 个过程、74 个触发器 | 运行维护与验收中的对应表及集成测试 |
| Java JDBC DAO、分页、批量、事务 | Store、Jdbc*Repository、JdbcQueryExecutor、CareService | 真实 MySQL 业务测试与路由契约 |
| 并发、权限与回滚 | src/test 下 DatabaseIntegrationTest、WorkflowIntegrationTest、HistoryRulesIntegrationTest | evidence/test-summary.json 中 125 项业务集成案例 |
| 分层、领域和接口验证 | ArchitectureTest、DomainRulesTest、RoutingTest、RouteContractIntegrationTest | 37 项独立测试及 1 项契约集成测试 |
| 安全与运维、索引及备份恢复 | Auth、JdbcScope、AesFieldCipher；运行维护与验收.md | 登录拒绝、越权、EXPLAIN、evidence/recovery.json |
| 小组报告、个人报告、PPT、源码等材料 | outputs、src、database、docs、evidence | 模板结构、文件内容与源码对应 |
| 真实分工、协作和答辩 | 报告蓝字位置及答辩讲解与录制脚本.md | 由实际成员填写和录制 |

课程评分中，基础实践占 40 分，小组报告及材料、个人报告、小组答辩各折合 20 分。基础实践报告属于另行完成的课程实验，本项目材料不能替代。技术验收包含需求、模型、DAO、SQL、安全与运行证据，不以表数、代码行数或测试总数单独判断得分。
