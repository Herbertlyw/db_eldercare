日期：2026-11-17。分支：`codex/role-interactions`。本地工作区包含尚未提交的改动，本轮未推送远程。

五个非管理员首页分别呈现老人照护、服务日程、机构人员管理、申报核验单和辖区监管。桌面截图为本地 18080 展示应用的实际页面，手机截图来自独立测试应用；两套数据库的业务记录有所不同。

## 验证结果

- TypeScript 检查、Prettier 格式检查、Vite 生产构建和 Maven 运行包打包通过。
- 前端单元测试 3 个文件、29 项通过，记录在 `unit-tests.log`。
- `verify_workspaces.cjs` 六角色首页通过，检查真实查询结果、老人切换与预约预选、日期选择与回到今天、证书跳转、机构排班入口、监管社区筛选与统计数值、审核入口、刷新与错误重试。各角色检查 1600、1280、768、390 像素宽度。
- `verify_layout.cjs` 六角色业务列表通过，包含空筛选恢复、手机详情、办理对象提示和四种宽度。
- 18080 实际运行包的六角色登录与页面加载通过，浏览器无脚本错误，检查过程未提交业务写入。运行包 SHA-256、内置前端与 HTTP 首页一致性见 `artifact-check.json`。

## 环境与边界

浏览器交互检查使用 18089 前端代理 18086 应用，连接独立真实 MySQL 库 `eldercare_home_ui20261117_test`，测试应用关闭定时任务；本轮未重建任何数据库。18080 展示应用保留定时任务配置，只进行登录与只读页面检查。

本轮修改前端布局、样式、浏览器检查与页面说明，无 Java 或 SQL 业务修改，未重复执行完整 Java/MySQL 回归。打包使用 `-DskipTests`，不能作为业务测试通过的依据。Vite 构建仍提示主 JavaScript 包超过 500 kB，本轮未处理代码分包。报告、PPT 和 Release 未更新。
